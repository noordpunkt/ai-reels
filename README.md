# ai-reels

Vertical 9:16 stories with 2D + 3D vector plates.

## Compositions

| ID | Story |
| --- | --- |
| `Roux` | How to make a roux, from *Le Lapin Bleu*. British English. Black studio plates. |
| `Roland303` | TB-303: from the 1981 flop to acid house |
| `Juno60` | JUNO-60: DCO, chorus, and the polysynth that fitted on stage |

The synth panels follow the original manuals (TB-303: TUNING / CUT OFF FREQ / RESONANCE / ENV MOD / DECAY / ACCENT; JUNO-60: LFO → DCO → HPF → VCF → VCA → CHORUS). Geometry, not scans.
